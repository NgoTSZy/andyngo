# 记录层 ID 撞号 · 逐条豁免表

用途：`node .check/record/newid.js --check` 读这张表。
**只有逐条登记过的历史撞号才被放行**；未登记的一律报缺陷（exit 5）。
登记了却找不到对应撞号的，按**悬空豁免**报缺陷（exit 6）—— 防止本表变成单方面清单。

**为什么需要这张表**：撞号的处置规则是「追加勘误、**不删行、不改行、不重编号**」（DEC-026），
所以那些行**永远**留在 `issues.md` / `decisions.md` 里。
若判据把它们**永远**报红，它就成了一条「**永远红的断言**」——
而永远红的断言会被看见、然后被训练成忽略（DEC-019）。
**但也不能区域级放行**（那等于没有判据），故只认逐条登记。

格式：`EX-ID-<序号> <编号>×<重复次数> <为什么放行> <仲裁依据>`

**新增豁免的门槛**：必须先有勘误处置（DEC-026），再把该撞号登记到这里。
**不得**为了「让检查变绿」而新增豁免 —— 那正是本表要防的事。
