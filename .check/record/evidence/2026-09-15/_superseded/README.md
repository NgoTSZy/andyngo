# _superseded —— 被取代/重复的留证

**本目录不参与 I5 判定**（I5 只读 `evidence/<日期>/` 顶层的 `w<wave>-j<job>-*.txt`，
子目录不在扫描面内）。放在这里是为了**不删任何东西**，同时让它们不再被算作作业留证。

## 为什么会有东西被放进来

### w8-j2-i5v2-vacuity-222145.txt（2026-09-15T14:21:45Z）

同一条命令执行了**两次**（沙箱内一次、升级后重试一次），第二次的 shell 重定向
`> "$OUT"` 在块执行前就创建了文件，于是两次各留下一个证据文件：

- `222145` —— 第一次运行的产物，**未被任何事件行引用** → 被 I5 判为「D2 孤儿留证」
- `222147` —— 第二次运行的产物，**被 EVT 009 引用**，保留在原地

两份内容仅时间戳与「谁是孤儿」的自身输出不同（diff 4 处），无信息损失。

**I5 抓到了它，判据是对的。** 这条记录同时暴露了 I5 的一个操作性特征：
**「留证文件已创建」与「事件行已写入」之间存在一个瞬时窗口，窗口内 I5 会报孤儿。**
这是正确的判定（此刻它确实无人引用），但要求操作顺序为「先写事件行、再跑 I5」。
