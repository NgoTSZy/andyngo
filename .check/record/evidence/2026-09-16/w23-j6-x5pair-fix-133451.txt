一 · 这个作业是什么（一句话）
──────────────────────────────────────────────────────────────────────
W23 J5 收尾跑全套验证时，X5 报出「本版**刚改、刚记录**的两个文件已过期」。
核对发现：**X5 的 md5 配对逻辑会静默错位** —— 12 条 STALE 里 **7 条是假的**（假阳性率 58%）。

四 · 修法（最小改动，机械确定）
──────────────────────────────────────────────────────────────────────
```js
/* 只从第 5 字段取改后 md5；按 `/` 切；与路径按索引配对；数不齐不猜。 */
const X5_SLASH = (field) => {
  if (field === '--' || field === '新增' || /（/.test(field)) return [];
  return field.split('/').map((s) => s.trim()).filter((s) => /^[0-9a-f]{32}$/.test(s));
};
const g = /^(CHG-\d{3}) (\S+) (\S+) (\S+) (\S+)/.exec(l);
const paths = X5_PARSE(g[3]);  const after = X5_SLASH(g[5]);
if (!after.length) continue;
if (after.length !== paths.length) { misaligned++; continue; }   /* 宁可不报，不报错 */
paths.forEach((p, i) => map.set(p, { id: g[1], md5: after[i] }));
```
设计取舍（刻意，已写进代码注释）：**「数不齐」时跳过而不是猜**。
代价：记录本身没有「一文件一 md5」对应关系时，**看不见那部分的腐烂**。
收益：**报告可信** —— 假阳性会让真问题淹死在噪声里。
