# L3 派工契约

## 硬约束
子代理不能再派子代理。L1 直接派发。

## 四种代理
| 类型 | 用途 | 返回 | 禁止返回 |
|------|------|------|----------|
| Explore | 纯调研 | 摘要清单 | 原始页面 |
| Plan | 架构设计 | 计划文档 | 探索笔记 |
| general-purpose | 实现 | 产物 + 判定 | 中间日志 |
| verifier | 独立验收 | 三态判定 + 缺陷清单 | 执行者自述 |

## 波次公式
WAVE 1: 独立步骤 → 一条消息并行
WAVE 2: 依赖步骤 → 等 WAVE 1 返回
WAVE 3: 实现（接口已写死）
WAVE 4: 独立验收 ∥

## 每次跳转成本
实测：一次 agent 跳转 ≈ 9.87 秒纯延迟。

## 只并行独立任务
| 情况 | 做法 |
|------|------|
| 时长相近（±30%） | 同波次 |
| 时长差 3 倍以上 | 长的先派 |
| 短任务依赖长任务 | 串行 |
| 短任务不依赖 | 并行 |

## 双向测规则（FIX 专用）
修完后故意改坏 → 必须报红。不报红 = 没齿。
