# 报告机制

## 五种形态
| 形态 | 何时 | 格式 |
|------|------|------|
| OK | 成功带数字 | OK <做了什么> <数字> |
| FAIL | 失败带归因 | FAIL <什么坏了> <归因> |
| ASK | 需用户决定 | ASK <问题> <默认>（配额 2） |
| PROGRESS | 执行中 | → <波次> <状态> <剩余> |
| BLOCK | 卡住 | BLOCK <卡在哪> <需要什么> |

PROGRESS 不消耗 ASK 配额。

## 报告频率
每个 Wave 报一次：
→ WAVE 1 派发 4 个 Explore ∥ 预估 3 分钟
→ WAVE 1 完成 4/4 耗时 2分41秒

## 去重
同一波次不重复报。等全部完成一次报。
例外：某代理超预估 2 倍未回 → 报一次超时。

## 状态显示（极简）
STATE  <phase> <n>/<total>
FILE   <path>

## 减少对话规则
- 无客套
- 无语气助词
- 直接展示状态
- 除非有问题回归，否则不追问
- 一行能说清的不写两行
