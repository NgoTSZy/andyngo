# 设计资源池

## 用法
不是收藏夹，是检索入口。
TASK 的 G2 必须写明"第 X 步用 design-pool 的 Y 层"。

## A · 配色 → 引用 sources.md L3 配色部分
## B · 字体 → 引用 sources.md L3 字体部分
## C · 图标 → 引用 sources.md L3 图标部分
## D · 组件 → 引用 sources.md L2
## E · 设计系统 → 引用 sources.md L1
## F · 声音 / 图片 / 动效 → 引用 sources.md L5

## 规则
- 优先已被大规模采用的（设计系统、事实标准调色板）
- 不选新出的个人作品
- 只参考代码 = 交付能跑但难看的东西
